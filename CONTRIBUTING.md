# Contributing

Contributions to the code and tests are welcome.


## Code Contributions

I do not profess to having the most immaculate coding style but if any bug
fixes or new features could match the existing style that would be great! Other 
than this, follow standard practices (fork, make changes, write/update tests, 
commit, push, and create pull request).

## Data Contributions

Avoiding the data leakage is one of the biggest concerns here. If you have a 
specific set of reactions (whether literature or another source) then follow 
the [data/data_template.csv](linkhere) for creating an input file. The list of 
existing reactions from the literature can be found in [data/literature.txt](linkhere). 
Check that the data is not present already.

## Model Performance

Should you find the model useful, or not performing in a specific chemical 
reaction space, it would be beneficial for the development of robust 
regioselectivity tools going forward to share this information. Please use the 
contact information below to reach out!
